# StreamChat 🎮📱

**StreamChat** — это клиентский мод для Minecraft (Fabric), который интегрирует чат из прямых трансляций TikTok Live прямо в вашу игру! 

Идеально подходит для стримеров, которые хотят общаться с аудиторией TikTok, не отвлекаясь от игрового процесса. Мод в реальном времени транслирует комментарии, подарки, лайки, подписки и информацию о новых зрителях во внутриигровой чат Minecraft.

### Особенности:
- 🚀 **Быстрое подключение:** Прямо в игре используйте команду `/tiktok connect <ваш_ник>`, чтобы мгновенно подключиться к стриму.
- ⚙️ **Гибкая настройка:** Полный контроль над тем, что вы хотите видеть. Отключайте спам от лайков или входов в конфигурационном файле.
- 🇷🇺 **Полная локализация:** Все уведомления переведены на русский язык и выглядят в точности как в приложении TikTok.
- 🧹 **Умный фильтр истории:** Мод игнорирует накопившийся бэклог чата при первом подключении, выводя только свежие и актуальные события.
