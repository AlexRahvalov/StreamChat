# StreamChat 🎮📱

**StreamChat** — это клиентский мод для Minecraft (Fabric), который интегрирует чат из прямых трансляций TikTok Live прямо в вашу игру! 

Идеально подходит для стримеров, которые хотят общаться с аудиторией TikTok, не отвлекаясь от игрового процесса. Мод в реальном времени транслирует комментарии, подарки, лайки, подписки и информацию о новых зрителях во внутриигровой чат Minecraft.

## 🚀 Суть проекта
Суть StreamChat заключается в создании бесшовного моста между стримером в Minecraft и его зрителями в TikTok. Вместо того чтобы использовать второй монитор или отвлекаться на телефон для чтения чата, стример может видеть все важные события прямо в игровом чате, поверх игрового процесса.

## ⚙️ Принцип работы
Мод использует неофициальную библиотеку `TikTokLive` (от JWDeveloper) для подключения к веб-сокетам трансляции TikTok.
1. **Подключение:** Вы вводите свой никнейм TikTok в конфигурацию или через команду `/tiktok connect <ваш_ник>`.
2. **Фоновый процесс:** Мод запускает отдельный легковесный поток, который подключается к серверам TikTok и начинает слушать события (сообщения, подарки, лайки и т.д.).
3. **Умная фильтрация:** Встроенный «фильтр истории» отсекает старые события (бэклог), которые приходят в первые 1,5 секунды после подключения, чтобы ваш внутриигровой чат не заспамило старыми сообщениями.
4. **Интеграция в игру:** Все новые и разрешённые в настройках события конвертируются в текстовые компоненты Minecraft (`Component`) с соответствующим цветовым форматированием (например, золотой цвет для платных подписок, розовый для подарков) и отправляются напрямую локальному игроку (`mc.player.sendSystemMessage`).

## 🛠️ Особенности и возможности:
- **Быстрое управление:** Используйте команду `/tiktok connect <ваш_ник>` для запуска и `/tiktok disconnect` для остановки трансляции событий.
- **Гибкая настройка:** Полный контроль над тем, что вы хотите видеть. В конфигурационном файле можно точечно включать или выключать отображение:
  - Комментариев
  - Подарков
  - Лайков
  - Новых подписчиков (Followers)
  - Поделившихся трансляцией (Shares)
  - Входов новых зрителей (Joins)
  - Платных подписок (Superfan Subscriptions)
- **Полная локализация:** Все уведомления выведены на русском языке и выглядят в точности как в приложении TikTok.

## 📥 Установка
1. Установите [Fabric Loader](https://fabricmc.net/) для вашей версии Minecraft (поддерживается версия ~26.1.2).
2. Поместите скомпилированный `.jar` файл мода (а также необходимые зависимости, включая Fabric API) в папку `mods` вашей игры.
3. Запустите игру. Конфигурационный файл будет создан автоматически, после чего вы сможете настроить мод под себя.
